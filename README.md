# 🔐 JWT Authentication SpringBoot

A backend authentication project built with **Spring Boot** and **Spring Security** that demonstrates secure user authentication and authorization using **JWT (JSON Web Tokens)**.

---

## ✨ Project Highlights

✔️ JWT-based Authentication

✔️ User Login & Authorization

✔️ Spring Security Integration

✔️ Protected REST APIs

✔️ Stateless Authentication

✔️ Secure Token Validation

---

## 🔄 Authentication Flow

```text
User Login
      │
      ▼
Username & Password
      │
      ▼
Spring Security
      │
      ▼
JWT Token Generated
      │
      ▼
Client Stores Token
      │
      ▼
Token Sent with Every Request
      │
      ▼
Protected API Access
```
